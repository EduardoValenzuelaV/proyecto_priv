# Fotografías

Agrega aquí fotos en formato JPG, PNG o WebP. Usa nombres simples, por ejemplo `paseo-paicavi.jpg`.

Para mostrarlas en `Dallana.html`, usa rutas relativas desde el HTML:

```html
<img src="assets/fotos/paseo-paicavi.jpg" alt="Nuestro paseo por Paicaví">
```

Optimiza las imágenes para web y evita incluir fotos que no quieras publicar: GitHub Pages hace públicos los archivos del repositorio.

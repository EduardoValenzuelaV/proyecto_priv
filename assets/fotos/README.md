# Fotografías

Aquí se guardan fotos locales del proyecto. La página actual referencia directamente `portada-musica.png`; otros archivos pueden ser originales, respaldos o estar asociados a contenido administrado por la API.

Antes de borrar una imagen, busca sus nombres en `Dallana.html`, `Dallana.css`, `Dallana.js` y en el archivo JSON de datos configurado para la API. Los archivos subidos al repositorio público son visibles en Internet.

Para añadir una foto enlazada desde el HTML, usa una ruta relativa:

```html
<img src="assets/fotos/paseo-paicavi.jpg" alt="Nuestro paseo por Paicaví">
```

Optimiza las imágenes para web y evita publicar fotos privadas.

# Stickers

Guarda aqui imagenes decorativas SVG o PNG con fondo transparente. Puedes usarlas en `Dallana.html` con una ruta relativa:

```html
<img src="assets/stickers/nombre-del-sticker.png" alt="" aria-hidden="true">
```

`stikers3.png` decora la portada junto al titulo. Los demas archivos `stikers*.png` aparecen junto a la nota.

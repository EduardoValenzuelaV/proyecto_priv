# Project brief

- **Goal**: un rincón web de regalo de Eduardo para Dallana: música, cartas, recuerdos, corazones diarios y Alejandro, un cangrejo pixel que la acompaña y hace de cartero entre los dos.
- **Non-goals**: cuentas de usuario, base de datos propia, app nativa.
- **Success criteria**: que Dallana quiera volver a diario; que todo funcione bien en su teléfono; que Eduardo sepa cuándo entra y pueda escribirle sin tocar código.
